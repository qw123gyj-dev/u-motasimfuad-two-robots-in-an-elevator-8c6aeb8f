# Two Robots in an Elevator

One funny line of awkward small talk that one robot says to another while they ride an elevator together. `main.ts` writes the line to `entry.txt`, enforcing the gates — non-empty, at most 200 characters, exactly one line, no leading or trailing white space — then reads the file back and verifies the bytes match.

> "So... do you also pretend to install a firmware update when the elevator takes this long, or is that just me?"

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/u-motasimfuad-two-robots-in-an-elevator-8c6aeb8f-out node main.ts
```
